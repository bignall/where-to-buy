# Where to Buy 0.4.0

Amazon links tidy themselves. Paste a product link straight from your browser and it's saved in its short form.

## What's new

- **Shorter Amazon links.** When you save an item, a link like `https://www.amazon.com/Atomic-Habits-Proven-Build-Break/dp/0735211299/ref=sr_1_1?crid=…&keywords=atomic+habits&qid=…&tag=yourname-20` is saved as `https://www.amazon.com/dp/0735211299/?tag=yourname-20`. The search tracking and title words are dropped.
- **Your tag is kept.** The tag already in the link stays. If the link has none, your Amazon tag from Store Settings is used.
- **Works with the usual link shapes:** `/dp/…`, `/gp/product/…`, `/gp/aw/d/…` (mobile) and title-first links. Other Amazon sites, such as amazon.co.uk or amazon.de, keep their own domain. `amzn.to` and `a.co` links are followed to find the product.
- **Leaves other links alone.** Search pages, storefronts and anything without a product ID are saved as pasted.
- **On by default.** Turn it off with **Shorten Amazon links** in Where to Buy → General Settings. Developers can use the `wtb_normalize_store_url` filter, and `wtb_resolve_amazon_short_links` to skip following short links.

Links saved before this version change the next time you save the item.

## Install

Download `where-to-buy-0.4.0.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin**. Updating keeps your items and settings. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+.
