# Where to Buy 0.6.0

Where to Buy now tells your to-do list when something needs fixing.

## New

- **Works with [To-do Hub](https://github.com/bignall/todo-hub).** When To-do Hub is active, Where to Buy adds:
  - **Fix store links on "item"** for each published item with a store link that doesn't show, with the reasons in the task's notes. It's high priority when no store button shows at all.
  - **Review N items waiting for approval** while items are pending review.

  Tasks are marked done when the problem is fixed, and removed when the item is unpublished or deleted. Items are checked when saved, when store settings change, and once a day, so a cloaked link that stops paying is caught too. It works with To-do Hub on this site or connected to a hub on another site. Turn it off under **General Settings → To-do list**.

## Install

Download `where-to-buy-0.6.0.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your items and settings are kept. See the [guide](https://bignall.github.io/where-to-buy/guide.html#todo).

Requires PHP 8.1+ and WordPress 6.4+. To-do Hub is optional.
