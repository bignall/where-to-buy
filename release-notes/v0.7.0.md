# Where to Buy 0.7.0

Move your recommendations to another site.

- **Move or back up** (General Settings):
  - **Export everything** downloads one file with your stores (affiliate tags, disclosures and button images), settings, categories and every item, with its links and images.
  - The images travel inside the file, so it works even when the old site is private.
- **Import a file** on the new site:
  - Stores are matched by name, so nothing is doubled up.
  - Items that are already there are skipped, so importing twice is safe.
  - The new site's web address is kept.
  - Cloaked links (Affiliate Link Cloaker) are matched by name on the new site. Where there's no match, the item links straight to the store, and the report lists it.
- **Moved to** (General Settings → Web address): after a move, item, list and category pages on the old site send visitors to the same page on the new site with a permanent (301) redirect, so links you've shared keep working.
