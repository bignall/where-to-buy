# Where to Buy 0.5.0

Ready-made pages for block themes, and a list page you can set up from settings.

## New

- **Templates for block themes.** On WordPress 6.7+ with a block theme (such as Twenty Twenty-Five), items and the Where to Buy list get a proper layout without building templates: photo beside the title, short description and store buttons on an item's page, and a grid of cards on the list and category pages. Your theme's own templates, or ones you change in the Site Editor, always take over.
- **List page settings.** General Settings → List page sets the title, an introduction, the disclosure shown once at the top, and a disclosure page to link to. Stores' own disclosures (such as Amazon's) are added for you.
- **Store buttons block** for templates and Query Loops: shows the buttons for whichever item it's in.
- **Shortcodes** for your own templates: `[where_to_buy_intro]`, `[where_to_buy_disclosure]`, `[where_to_buy_back]`, `[where_to_buy_categories]` (category links), and `[where_to_buy_buttons notes="0"]`.

## Fixed

- The buy box no longer shows twice on an item's page when the template already places it above the content.

## Install

Download `where-to-buy-0.5.0.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your items and settings are kept. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+ (templates need 6.7+).
