# Where to Buy 0.11.0

Getting ready for WordPress.org.

## Changes

- Links to the paid add-ons, [Where to Buy Pro](https://rbcreativesolutions.net/where-to-buy-pro/) and [Where to Buy Templates](https://rbcreativesolutions.net/where-to-buy-templates/): under the plugin on the Plugins screen, and in a short Add-ons box at the bottom of **General Settings**. Each one disappears once that add-on is active.
- Tested with WordPress 7.1.
- The readme now has Installation, Add-ons and External services sections.
- Fixes from WordPress.org's Plugin Check. Nothing you'd notice: links and settings work as before.
