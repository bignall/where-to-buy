# Where to Buy 0.3.1

The first public release. Show where to buy the things you recommend: a photo, a short description and a button for each store that sells it, with affiliate disclosures built in.

## What's in it

- **Stores, set up once** in Where to Buy → Store Settings: name, button image, allowed domains, affiliate tag and extra disclosure. Drag to reorder. A default image covers stores without their own.
- **Only working links show.** A link must be a full web address on the store's own domain. The item editor says which links show and why the others don't.
- **Disclosures built in.** Your note shows under the buttons, and Amazon's Associates sentence is added whenever an Amazon button shows. Links carry `rel="sponsored nofollow noopener"`.
- **Place items anywhere:** item pages, a list page at `/where-to-buy/` (the slug can be changed), the Where to Buy block, and the `[where_to_buy]`, `[where_to_buy_buttons]` and `[where_to_buy_list]` shortcodes.
- **Works with Affiliate Link Cloaker:** any store can use a cloaked `/go/` link, and links to ended offers are hidden.

## Install

Download `where-to-buy-0.3.1.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin**. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+.
