# Where to Buy 0.4.2

Category pages now look like the rest of Where to Buy.

## Fixed

- **Category pages use the list page's design.** Pages like `/where-to-buy/category/books/` now use the same template as the main Where to Buy list, showing that category's items. Before, themes without a category template (Etch, for one) fell back to a bare default page that showed only one item's description.
- If your theme has its own `taxonomy-wtb_item_category` template, that's still used instead.

## Install

Download `where-to-buy-0.4.2.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your items and settings are kept. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+.
