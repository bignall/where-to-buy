# Where to Buy 0.4.1

A fix for category pages.

## Fixed

- **Category pages work again.** Addresses like `/where-to-buy/category/books/` showed "not found", even after saving permalinks, because the item address rules caught them before the category rule did. Category rules now come first.

The address rules are rebuilt automatically when you update, so there's nothing else to do. If you'd set up a redirect away from category pages as a workaround, you can remove it.

## Install

Download `where-to-buy-0.4.1.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your items and settings are kept. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+.
