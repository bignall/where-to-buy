# Where to Buy 0.8.0

eBay joins the default stores, and store logos are now a free download.

## What's new

- **eBay** is one of the stores new installs start with, alongside Amazon, Walmart, Best Buy, Target and Chewy. Its links must go to ebay.com or ebay.us. Already using Where to Buy? Add it in **Where to Buy → Store Settings → Add store** (name eBay, domains `ebay.com, ebay.us`).
- **Store logos download.** `where-to-buy-store-logos.zip`, attached below, has logos for all six stores as PNGs ready to upload as button images, plus SVGs. Most stores come in several versions: the full logo, a small icon (Amazon's "a", Walmart's spark, Target's bullseye) and white versions of Amazon and Best Buy for dark buttons. Store Settings links to it too.

The logos are public domain files from Wikimedia Commons, but they're still the stores' trademarks. The README in the zip lists where each came from; check each store's brand rules before using its logo.

## Install

Download `where-to-buy-0.8.0.zip` below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded**. Your items and settings are kept. See the [guide](https://bignall.github.io/where-to-buy/guide.html).

Requires PHP 8.1+ and WordPress 6.4+.
