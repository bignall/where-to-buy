# Store logos for Where to Buy

Logos for the stores Where to Buy starts with, to use as store button images.

## Using them

1. In WordPress, go to **Where to Buy → Store Settings**.
2. Next to a store, under **Button image**, click **Choose** and upload the logo from the `png` folder.
3. Save.

Use the PNG files. WordPress doesn't accept SVG uploads unless a plugin allows them. The PNGs are 256 pixels tall with see-through backgrounds, which stays sharp at button size on high-resolution screens.

The `-white` versions are for dark buttons: the dark text is white and the colours are unchanged.

## Copyright and trademarks

Every file here comes from Wikimedia Commons, where each one is marked **public domain**: they're simple shapes and lettering, so they can't be copyrighted. The only changes are a `viewBox` added to some SVGs so they scale, and the white versions noted above.

They are still **trademarks** of Amazon, Walmart, Best Buy, Target, Chewy and eBay. Showing a store's logo on a "buy it here" button is the usual way to use them, but each company has its own brand rules. Check them before you use a logo, and don't stretch, crop or recolour it beyond what those rules allow. Where to Buy and RB Creative Solutions aren't connected with or endorsed by any of these companies. If you'd rather not use the logos, leave **Button image** empty and the store shows as a text button.
