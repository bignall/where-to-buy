# Store logos for Where to Buy

Logos for the stores Where to Buy knows about, to use as store button images. REI and Bookshop.org aren't included: there are no freely licensed copies of their logos to share.

## Using them

1. In WordPress, go to **Where to Buy → Store Settings** and click **Add logos from your computer**.
2. Open the `png` folder and select the logos you want. Selecting them all is fine: each goes to the store it's named after (`amazon.png` to Amazon), and when there are several versions, the store's main logo is used.
3. Click **Save Changes**.

To use a different version for one store (say `amazon-white.png` on a dark button), click **Upload** next to that store and pick the file.

Use the PNG files. WordPress doesn't accept SVG uploads unless a plugin allows them. The PNGs are 256 pixels tall (Barnes & Noble's very wide logo is 1600 pixels wide instead) with see-through backgrounds, which stays sharp at button size on high-resolution screens.

The `-white` versions are for dark buttons: the dark text is white and the colours are unchanged.

## Copyright and trademarks

Every file here comes from Wikimedia Commons, where each one is marked **public domain**: they're simple shapes and lettering, so they can't be copyrighted. The only changes are a `viewBox` added to some SVGs so they scale, and the white versions noted above.

They are still **trademarks** of the companies they belong to. Showing a store's logo on a "buy it here" button is the usual way to use them, but each company has its own brand rules. Check them before you use a logo, and don't stretch, crop or recolour it beyond what those rules allow. Where to Buy and RB Creative Solutions aren't connected with or endorsed by any of these companies. If you'd rather not use the logos, leave **Button image** empty and the store shows as a text button.
